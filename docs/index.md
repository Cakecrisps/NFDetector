# Документация NFDetector

NFDetector наблюдает трафик и создаёт инциденты по пороговым правилам.
Агенты сохраняют полный PCAP, сервер выполняет анализ. Это пассивная IDS:
автоматической блокировки и подтверждения успешной компрометации нет.

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `distributed/` | API, агент, очереди, workers, checkpoints, инциденты, веб-аутентификация |
| `distributed/web/` | Статическая веб-панель |
| `general/` | Детекторы, протоколы аутентификации и локальный монитор |
| `nfdetect.py` | Локальная CLI через PyShark/TShark |
| `compose*.yaml`, `infra/` | Серверная инфраструктура и TLS LB |
| `rules.json`, `ext/` | Правила и списки адресов |
| `tests/`, `_test.py`, `benchmarks/` | Тесты и измерения |
| `docs/` | Единственный источник руководства в Markdown |
| `documentation/` | Сгенерированные HTML руководства и Python API |
| `scripts/build_docs.py` | Сборка и проверка ссылок |

`cap.pcap` и `out/` — исторические примеры; они не описывают состояние текущей
установки и не являются тестом производительности.
