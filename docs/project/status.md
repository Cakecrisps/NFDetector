## Что изменено при приведении документации в порядок

- В корне остался короткий README с точками входа.
- Руководства разделены на установку, работу с системой, архитектуру,
  состояние проекта и разработку внутри `docs/`.
- Удалён старый проект архитектуры, обещавший ещё не реализованные shards,
  retention и доставщик. Текущая модель описана отдельно от плана.
- Уточнены реальные пороги, SSH-эвристика, смысл защищаемых адресов,
  ограничения L7, квоты и временная основа статистики.
- Удалены устаревшие примеры SIEM URL, не поддерживаемые локальным HTTP logger.
- HTML собирается MkDocs, API-справочник — pydoctor по явному списку исходников.
  Обход `.git`, логов, PCAP и окружений исключён.

Проверенные сценарии и то, что пока не проверено, перечислены в [отчёте](audit.md).
Наличие функции в коде не заменяет проверку конкретной установки.
