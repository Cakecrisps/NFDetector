# Ограничения и границы гарантий

| Область | Текущее поведение | Следствие |
| --- | --- | --- |
| Время | Часы согласованы; последовательные файлы не уходят назад по времени | Обратный диапазон останавливает домен; коррекции часов нет |
| Idle-источник | Watermark ждёт каждый незакрытый поток | Тихий/пропавший агент задерживает анализ остальных |
| Масштабирование | Один reducer на домен | N parser не снимают предел CPU/сериализации домена |
| Повторное наблюдение | Дедупликация файлов, но не пакетов разных сенсоров | Перекрывающиеся сенсоры завышают пороги |
| Хранение | Сервер не удаляет PCAP/JSONL автоматически | 2 GiB PCAP на агента заканчиваются `429`; JSONL, БД и orphan-файлы требуют отдельного бюджета |
| Доступность | Один хост, PostgreSQL, API и LB | Volumes переживают рестарт, но не потерю хоста/диска |
| Конфигурация | Hash правил и адресов входит в checkpoint | Смена правил требует replay/миграции |
| Уведомления | Outbox записывается, доставщика нет | Инцидент не означает отправку в SIEM/мессенджер |
| Доступ | Панель администратора и индивидуальные ключи загрузки | Нет ролей и изоляции нескольких организаций |
| Checkpoint | Доверенный pickle, предел 64 MiB до сжатия | Нужен доверенный DB-доступ; превышение останавливает домен |

## Пакеты и протоколы

Серверный parser (`dpkt`) принимает PCAP и ограниченный PCAPNG: одна секция,
один интерфейс, Enhanced Packet Blocks. Поддержаны Ethernet/VLAN, raw IP,
Linux SLL/SLL2, IPv4/IPv6. Усечённые кадры, IPv6-фрагментация и некоторые
PCAPNG layouts приводят к ошибке файла. Файл сначала разбирается в список
и сортируется в RAM: лимит 500 000 кадров не равен гарантии малого RSS.
JSONL с hex-payload может быть существенно больше PCAP.

IPv4-фрагменты и TCP-сегменты собираются между файлами. Прикладной decoder
ограничен HTTP/1.x, HTTP Basic, FTP, TELNET, SMB/SMB2 Session Setup и SSH banners.
TLS, HTTP/2, QUIC и зашифрованная SSH-аутентификация не анализируются на уровне
содержимого. Байты до начала захвата восстановить нельзя.

Ошибки reassembly/прикладных сообщений дают `DECODE_WARNING`, очищают
состояние затронутого flow и сохраняют L3/L4-анализ. Это не подтверждение атаки.
Статистика протоколов отражает классификацию parser на уровне транспорта,
а не полный L7-разбор TShark; прочие категории попадают в `OTHER`.

## Качество детектирования

SSH greeting rate — возможный перебор, не число ошибок пароля. Пороговый
DDoS может совпасть с легитимным всплеском. C2 считает интервалы пакетов пары
IP, а не доказанные новые соединения с управляющим сервером. Для подтверждения
нужны журналы сервисов, контекст нагрузки и исходный PCAP.

При capture loss, односторонней видимости, NAT, offloading или рассинхронизации
часов полнота анализа ограничена качеством входа. Heartbeat не содержит
достоверного счётчика потерь dumpcap; зелёный статус не доказывает полноту захвата.

При заполнении spool агент останавливает захват, сохраняя неподтверждённые
файлы. Новые пакеты в период остановки не наблюдаются. Первый запуск capture
требует соединения с сервером для регистрации потока; автономного старта нет.
