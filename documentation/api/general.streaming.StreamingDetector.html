class StreamingDetector:

Constructor: StreamingDetector(analyzer)

View In Hierarchy

One ordered capture stream. Emit rate alarms on threshold crossings.

State is scoped to an observation domain. Disjoint sensor streams may be merged in event-time order upstream. Late packets are rejected before state is changed.
