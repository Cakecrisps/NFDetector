distributed

package documentation

Durable PCAP ingestion, parallel parsing and shared detection.

Module agent Crash-resumable capture uploader. Secrets are read from a private file.
Module api Authenticated binary upload API. No public endpoint issues administrative keys.
Module capture Bounded, stateless L2/L3/L4 PCAP parsing. Application state lives downstream.
Module flows TCP/application and IPv4 fragment state, shared across parsed PCAP files.
Module incidents Batch ongoing detector activity into event-time incidents, retaining raw evidence.
Module installation One-time agent enrollment and reproducible, secret-free installation artifacts.
Module installer Downloaded by a digest-checked bootstrap. This file uses Python stdlib only.
Module service Managed agent entry point; credentials stay in private files, never argv.
Module settings Environment configuration shared by service processes.
Module store PostgreSQL coordination. All publication is fenced by owner and generation.
Module tls Explicit leaf certificate authentication for agents installed from the panel.
Module web Browser administration served by the existing API behind the existing TLS LB.
Module web_auth Separate browser authentication with one-time setup, Argon2 and server-side sessions.
Module web_metrics Period statistics from one database snapshot; timestamps are UTC-aware.
Module web_security Response hardening and a small request budget for browser administration.
Module workers Parallel file jobs and fenced, restartable domain event-time reducers.
