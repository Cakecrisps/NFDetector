def reduce_batch(store, domain, state, observations=None): ¶

Merge ready file prefixes only up to every registered source's watermark.

Each source must have non-overlapping timestamp ranges between consecutive chunks. Missing files hold the watermark, including a missing sequence zero. The same domain must contain disjoint observation sources with aligned clocks.
