Проверки разработчика¶

Окружение¶

Python 3.10+; текущие полные прогоны выполнены на Python 3.12.

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q

Без NF_TEST_DATABASE_URL интеграционные тесты пропускаются. Это не полный успешный прогон. Тесты с БД создают собственные временные schemas, затем удаляют их; используйте отдельную одноразовую БД, не production.

docker run -d --rm --name nfdetector-test-db \
  -e POSTGRES_DB=nfdetect -e POSTGRES_USER=nfdetect \
  -e POSTGRES_HOST_AUTH_METHOD=trust \
  -p 127.0.0.1:55439:5432 postgres:16-alpine
docker exec nfdetector-test-db pg_isready -U nfdetect -d nfdetect
NF_TEST_DATABASE_URL=postgresql://nfdetect@127.0.0.1:55439/nfdetect \
  .venv/bin/python -m pytest -q
docker stop nfdetector-test-db

Дождитесь положительного ответа pg_isready перед тестами. Trust-аутентификация здесь относится только к временной БД на loopback и не является настройкой сервера.

Изолированный HTTPS smoke-test¶

python3 -m benchmarks.compose_smoke \
  --server https://localhost:8443 --key-file .local/test-agent.key \
  --ca .local/server.crt

Требуются отдельный Compose project и новый домен, защищаемый 192.168.1.1, пороги DDoS=3, HTTP=2, brute force HTTP Basic=2, HTTP Basic в auth_proto, отключённый C2. Подключайте тестовые rules и ext отдельными override mounts; рабочие настройки не изменяйте ради smoke-test. Нужно минимум два parser-worker. Скрипт генерирует синтетический PCAP, проверяет разных владельцев parser, обратный порядок завершения файлов и обнаружение правил через объединённые инциденты. Смену reducer и восстановление checkpoint отдельно проверяют интеграционные тесты. Код: benchmarks/compose_smoke.py.

Нагрузочный микробенчмарк описан отдельно в производительности. Тесты корректности не дают гарантии заданного packets/s и отсутствия capture loss.

Документация¶

python3 -m pip install -r requirements-docs.txt
python3 scripts/build_docs.py

Сборка проверяет структуру навигации, локальные ссылки и anchors HTML; удалённые сайты для неё не запрашиваются. См. процесс сборки.
