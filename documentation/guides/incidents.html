Инциденты и исходные срабатывания¶

Панель и /v1/events показывают инциденты. Связанные DDoS_SINGLE_IP, DDoS_MULTI_IP, SYN flood и HTTP flood на одну цель в одном домене объединяются в один DDOS, включая несколько источников и агентов. SSH-перебор разделяется по источнику, цели и порту; другие типы правил остаются отдельными.

Сохраняются начало обнаружения, последняя активность, длительность, список правил, число исходных срабатываний и до 100 наблюдаемых источников с признаком усечения. Детектор обновляет активность при сохраняющемся превышении порога, даже если новых пересечений порога нет: непрерывный час атаки даёт час активности. Записи обновляются пакетами reducer, без SQL-запроса на каждый сетевой пакет.

Пауза до NF_INCIDENT_GAP_SECONDS (по умолчанию 300 секунд) остаётся внутри инцидента. Более длинная пауза начинает новый инцидент. Закрытие по тишине происходит только после продвижения времени обработанных пакетов: задержка доставки или остановка worker не выдаётся за завершение атаки. При отсутствии свежего трафика панель показывает «Нет свежих данных». Полностью обработанный закрытый захват помечается «Захват завершён»; окончание самой атаки за границей захвата неизвестно. Период ожидания закрытия не добавляется к длительности.

nf_events сохраняет исходные срабатывания и их связь с nf_incidents. В nf_incident_outbox создаётся одна запись на инцидент; повторные срабатывания не создают новых уведомлений. При интеграции доставщика используйте эту таблицу; старый nf_outbox оставлен для совместимости с историческими данными.

Для существующей БД после обновления можно объединить старые срабатывания: остановите detector-worker, дождитесь освобождения его lease, выполните docker compose run --rm --no-deps api backfill-incidents --domain main и снова запустите worker. Команда идемпотентна, не удаляет исходные срабатывания и не меняет checkpoint. Историческая длительность при таком переносе ограничена временем исходных срабатываний. Для восстановления непрерывной активности между ними требуется повторный анализ сохранённого захвата.

С ошибкой parser файл остаётся в статусе error, с ошибкой reducer останавливается соответствующий домен. Ошибки и пробелы не обходятся молча. Для изменения правил или повторного анализа создайте отдельный домен и отправьте исходники заново: checkpoint содержит hash правил и не применяется к другой конфигурации.

Проверка сигнала¶

Инцидент сообщает о наблюдаемом поведении. Успешная атака, отказ сервиса и неудачный вход требуют дополнительного подтверждения: журналами сервиса, доступностью цели и исходными пакетами.
