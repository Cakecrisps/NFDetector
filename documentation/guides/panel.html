Веб-панель¶

Панель открывается по тому же адресу https://detector.example.com/ и использует тот же сертификат LB. Новых внешних портов нет. Для удалённого веб-доступа в .env нужно задать точный origin без завершающего /:

NF_PUBLIC_URL=https://detector.example.com

Без NF_PUBLIC_URL первоначальная настройка разрешена только через localhost/loopback. Для локального порта, например, используйте https://localhost:8443. LB сохраняет исходный Host с портом и сам устанавливает доверенный адрес клиента. API остаётся доступным только в закрытой Docker-сети.

Первый вход¶

При первой установке создаётся пользователь приложения root с паролем root. Это не системная учётная запись контейнера. Для защиты от перехвата первоначальной настройки первый вход дополнительно требует одноразовый код с сервера:

docker compose exec -T api python -m distributed setup-code

При запуске с собственным сертификатом добавляйте те же -f compose.yaml -f compose.tls.yaml, что использовались при старте. Код хранится в приватном файле data-volume с правами 0600, в PostgreSQL находится только его hash. Он не выдаётся через HTTP и не печатается в startup-лог.

После входа доступен только экран обязательной смены пароля. До смены даже прямой вызов API статистики, ключей и событий запрещён сервером. Новый пароль должен содержать 15–128 символов и отличаться от прежнего. После смены root:root и код установки перестают работать; прежние сессии отзываются. Перезапуск и обновление контейнера первоначальный пароль не восстанавливают.

Разделы панели¶

  • Обзор: агенты на связи, число пакетов, захваченные байты, инциденты за выбранный период, график поступления PCAP, распределение протоколов и последние события.

  • Агенты: поиск, последняя связь, состояние захвата, очередь на сенсоре, потоки, выпуск/замена/отзыв ключей. Секрет показывается один раз; его можно скопировать или скачать. Замена немедленно отключает прежний ключ, история агента остаётся на месте.

  • Трафик: период 1 час / сутки / неделя, объём принятых PCAP, число пакетов, разобранные байты, очередь файлов, ошибки и состояние доменов.
  • События: фильтрация по типу, поиск по IP/агенту/тексту, страницы и детали с capture-временем и временем получения.
  • Безопасность: смена пароля и журнал входов/административных действий.

На страницах «Обзор» и «Трафик» общий переключатель выбирает последний час, 24 часа или 7 дней. Карточки, график и протоколы считаются за один диапазон из одного снимка PostgreSQL. Час разбит на 60 минут, сутки — на 96 интервалов по 15 минут, неделя — на 168 часовых интервалов. Суммы графика совпадают с карточками; пустые интервалы показаны нулями. Наведение или клавиши стрелок на графике показывают объём, пакеты и файлы конкретного интервала.

Файлы, байты и протоколы отбираются по времени приёма сервером, не по датам внутри PCAP. PCAP-байты (с заголовками файла) и захваченные сетевые байты показаны отдельно. Поэтому поздняя загрузка старого PCAP попадает в сегодняшний график приёма. Инцидент учитывается в периоде, если его наблюдаемая активность пересекается с этим периодом. Агенты на связи и состояние доменов показывают текущее состояние; последние инциденты отдельно помечены как список за все периоды.

Выбор светлой, тёмной или системной темы доступен в верхней панели и на экране входа. Системная тема следует настройке ОС. В localStorage сохраняется только значение nf-theme; пароли, ключи и сессии туда не записываются. Тема применяется до загрузки стилей, без inline-скриптов и ослабления CSP.

Новая версия агента отправляет heartbeat каждые 10 секунд во время работы, включая состояние и размер локальной очереди. Связь считается свежей 60 секунд. Статус отражает последние данные, полученные сервером, а не сетевой ping сенсора. Захваченные байты считаются по кадрам при разборе; объём PCAP включает заголовки файлов. У ранее разобранных файлов может отсутствовать новая статистика протоколов и байтов — панель помечает такую неполноту.

Защита веб-доступа¶

Пароли хранятся через Argon2id. Сессии — на сервере, в браузере только случайный Secure, HttpOnly, SameSite=Strict cookie с префиксом __Host-, без Domain. Срок — до 8 часов, время без действий пользователя — 30 минут. Для управления ключами через 5 минут после входа требуется повторное подтверждение пароля.

Мутации защищены session-bound CSRF-токеном и проверкой точного Origin. Предусмотрены ограничение попыток входа, ограничение тела административного запроса, CSP без inline-скриптов/стилей, запрет встраивания, no-store и отзыв всех сессий при смене пароля. Ключ агента не даёт административного веб-доступа; веб-cookie не заменяет ключ агента. Пароли, cookies, код настройки и секреты ключей не записываются в журнал администратора. Данные агентов и событий выводятся как текст, без интерпретации HTML.

На публичном сервере оставляйте HTTPS на LB. NF_TRUST_PROXY_HEADERS=1 задан в Compose для закрытого API; при другом развёртывании доверять заголовкам клиента можно только за прокси, который их перезаписывает.
